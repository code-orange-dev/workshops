# Bitcoin Node Workshop

> Don't trust, verify. Learn to run your own full Bitcoin node.

---

## Overview

This workshop walks participants through setting up and running a Bitcoin full node. Attendees learn why running a node matters for sovereignty, how to set one up on Umbrel or Bitcoin Core, and how to connect their wallet to their own node.

**Format**: In-person
**Frequency**: Quarterly
**Location**: Bitcoin House Bali
**Audience**: Beginners to intermediate
**Cost**: Free

---

## What We Cover

- Why run a full node — validating your own transactions
- Don't trust, verify — the ethos of self-sovereignty
- Setting up Umbrel on a Raspberry Pi or old laptop
- Bitcoin Core installation and initial block download
- Connecting Sparrow/Electrum wallet to your own node
- Tor configuration for privacy
- Node maintenance and monitoring

## Run This Workshop in Your City

1. Download the slides: [GitHub](https://github.com/code-orange-dev/bitcoin-node-workshop-slides)
2. Pre-sync an Umbrel node (IBD takes hours — don't do it live)
3. Have participants bring laptops to install Bitcoin Core or connect to your demo node
4. Budget 2 hours
5. Combine with self-custody for a full sovereignty day
