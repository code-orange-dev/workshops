# OpenClaw / Vibe Coding on Nostr Workshop

> Build freedom apps using AI tools - no coding experience required.

---

## Overview

The Vibe Coding workshop series (now branded **OpenClaw**) teaches Bitcoiners to build websites, apps, and tools using AI-assisted development. Started as "Vibe Coding on Nostr" in July 2025, it evolved into a broader monthly program covering AI-assisted custody, Lightning L402 payments, Nostr website building, and bot automation.

**Format**: In-person (Bitcoin House Bali) + Online (Discord)
**Frequency**: Monthly (every 3rd Wednesday, 8pm UTC+8 - now expanded)
**Audience**: Non-coders and beginners
**Cost**: Free

---

## What We Cover

### Nostr Website Building
- Build a website on Nostr in under 15 minutes using Soapbox Shakespeare / MKStack
- Deploy to the decentralized web
- No hosting costs, no censorship possible
- Community members building educational websites for Bitcoin Dojo questions

### AI-Assisted Development
- Soapbox Shakespeare (ShakespeareDIY) - AI web builder for Nostr
- Replit - vibe coded a website in under 30 minutes
- Cursor AI - building Cashu payment widgets
- OpenClaw / Clawi AI - AI assistants running on Umbrel

### Bitcoin Integration
- L402 Lightning payments - authenticated API access
- Alby - Lightning wallet + Nostr zaps
- Cashu payment widgets on Nostr sites
- Breez SDK integration for Bitcoin payments

### OpenClaw (Current Format)
- AI-assisted custody with Nunchuk
- Lightning L402 payments
- Nostr website building with Soapbox Shakespeare
- Nostr bot zapping with Alby
- Setting up OpenClaw/Clawi AI assistant on Umbrel while running a Bitcoin node

## Run This Workshop in Your City

1. Open [Shakespeare](https://shakespeare.diy), the AI web builder by [Soapbox](https://soapbox.pub) (ask your facilitator about participant credits)
2. Have participants bring laptops - everything is browser-based
3. Start simple: "build your first website in 15 minutes"
4. Progress to Bitcoin integration: Lightning payments, Cashu widgets
5. Works great online (Discord screen-share) or in-person
6. Budget 1.5-2 hours
