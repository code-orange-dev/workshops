# Decoding Bitcoin Study Cohort

> 8 weeks decoding how Bitcoin actually works under the hood.

---

## Overview

Decoding Bitcoin is an 8-week study cohort based on the [Bitcoin Dev Project's](https://bitcoindevs.xyz) Decoding Bitcoin curriculum, built by @jrakibi. Participants study Bitcoin's internals - transactions, Script, SegWit, Taproot - and graduate into open-source contribution with guidance on grant applications.

**Format**: Online (Discord) - weekly calls
**Duration**: 8 weeks
**Partners**: Bitcoin Dev Project (@jrakibi)
**Audience**: Developers with basic programming knowledge
**Cost**: Free
**Status**: 2 cohorts graduated (12+ graduates)

## Syllabus

| Week | Topic |
|------|-------|
| 1 | Bitcoin Fundamentals - regtest, CLI, block structure |
| 2 | Transactions Deep Dive - inputs, outputs, UTXO model |
| 3 | Bitcoin Script - opcodes, stack machine, P2PKH |
| 4 | SegWit - witness data, BIP141, P2WPKH, P2WSH |
| 5 | Taproot - Schnorr signatures, MAST, P2TR |
| 6 | PSBTs & Multisig - partially signed transactions, BIP174 |
| 7 | Bitcoin Core Architecture - source code tour, build system |
| 8 | First OSS Contribution - Good First Issues, PR workflow |
